# RikaTechno Bingo — GitHub Pages

Sorteador de bingo gratuito para navegador, modalidades 75 e 90 números, sem repetição, anúncio por voz, sorteio automático/manual, tela cheia e histórico local.

## Publicar no GitHub Pages

1. No GitHub, crie um repositório **público** chamado `rikatechno-bingo`, com opção **Add a README** desmarcada.
2. Entre no repositório e escolha **Add file > Upload files**. Envie os arquivos `index.html` e `README.md` (não envie o ZIP).
3. Confirme com **Commit changes**.
4. Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/(root)` e clique em **Save**.
5. Acesse `https://dapper121-sketch.github.io/rikatechno-bingo/` quando a publicação terminar.

## Atenção

Esta versão do GitHub Pages opera **localmente por navegador**: o sorteio é salvo no armazenamento local e não sincroniza vários dispositivos. Para painel público sincronizado em tempo real e senha de organizador, será necessária integração com um backend (por exemplo, Supabase) e controle de acesso seguro; não insira credenciais secretas diretamente no HTML.
